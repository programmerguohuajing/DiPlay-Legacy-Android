# DiPlay v0.3.8 — 32kHz麦克风回退采样修复老车通话上行静音、有线USB卡死STALL收敛提示重启

## 更新

- **32000 Hz 麦克风请求增加回退采样率与重采样支持**（Issue #360）：
  - 修复部分老旧车机（如 RK3188 / Android 4.4.4）音频驱动对 32000 Hz 查询最小缓冲区直接返回 -1，导致通话上行在 `MIN_BUFFER` 阶段立即中断、通话时对方完全听不到声音的缺陷；
  - 为 32000 Hz 录音请求增加回退采样机制：优先以 48000 Hz 录音并通过全新的 3:2 降采样转换，或以 16000 Hz 录音并通过 1:2 升采样转换；
  - 修正录音缓冲区尺度向上取整计算（48kHz 对应 32kHz 请求需要 1.5 倍帧字节），并按采样率比例精准分配采集缓冲区，彻底消除重采样转换截断。
- **有线连接 iPhone USB 状态卡死在 STALL 时停止无限重试并提示重启**（Issue #359）：
  - 修复 iPhone 经历底层断开后拒绝所有 USB 配置请求（连续 USB STALL），导致应用在 30 秒间隔下陷入数十甚至数百次无休止重试死循环的问题；
  - 引入与 USB 忙碌相同的收敛机制：当连续 3 次失败原因均包含全 STALL 提示时，主动停止自动重试循环，提供手动重试按钮并明确提示用户“拔出连接线，重启 iPhone，然后重新连接”；已同步补齐全部 7 种语言本地化文案。
