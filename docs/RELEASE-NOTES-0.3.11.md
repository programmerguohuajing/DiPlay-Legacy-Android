# DiPlay v0.3.11 — 倒车退出防误判抢屏、播报时媒体音量压低、NCM卡死恢复与热点失败网卡保护

## 更新

- **倒车退出增加焦点确认与防抖机制，彻底消除倒车中途误抢屏**（Issue #315, #363）：
  - 修复在倒车调头过程中 CAN 信号抖动产生短暂 camera-off 状态导致应用无条件重建画面、CarPlay 强行挤占原厂倒车影像的缺陷；
  - 退出恢复增加 600ms 观察窗口并严格确认窗口真实获得焦点，倒车再次激活立即撤销待执行的恢复任务；倒车期间屏蔽全屏重申与画面刷新，杜绝原厂影像被意外切除。
- **语音播报音频流活跃时自动压低媒体音乐音量（高级设置，实验性）**（Issue #364）：
  - 新增实验性选项：当检测到导航、Siri 或电话等辅助音频通道有实际 PCM 写入时，自动压低媒体音乐音量，提示音结束约 1.5 秒后自动平滑恢复原音量；
  - 深度结合焦点协调器，有效音量取焦点音量与压低音量最小值，防止播报中途焦点恢复导致提前回弹，确保驾驶播报清晰可辨。
- **NCM 数据接口连续 bulk-OUT 零完成卡死时重新 Claim 恢复**（Issue #75）：
  - 修复特定车机内核上有线 NCM 连接在握手成功后出现数据包持续提交但完成数持续为 0（零完成卡死）导致网络中断的问题；
  - 在第 12 次失败时定向触发释放数据接口、强制重新 Claim 并重选 alternate setting，在不重启 USB 总线的前提下唤醒卡死端点。
- **限制每个会话至多一次 MainAudio 索回，去重并发 USB 权限申请**（Issue #305, #293）：
  - 修复有线模式下音频焦点变化与触摸事件短时间内频繁发送 MainAudio Untake 导致 iPhone 停止响应关键帧、画面彻底冻结的隐患；
  - 对 12ms 内由不同检测路径触发的并发 USB 设备权限弹窗进行去重，防止二次申请冲刷系统对话框导致误判拒绝。
- **hostapd 热点启动失败清理时保护网卡与无线电状态**（Issue #330, #348）：
  - 修复部分本田等车机在 hostapd 启动失败后全量 teardown 停用 wlan0 导致网卡死锁、直至重启车机前无法再次绑定的严重问题；
  - 启动失败清理仅终止守护进程并删除敏感凭证文件，不再停用物理接口或关闭 Wi-Fi 无线电。
