# DiPlay v0.3.10 — 依据视图实例锁定过渡缩小防护基线、粘性全屏防黑边及前台热点探针独立日志

## 更新

- **依据 SurfaceView 实例确立过渡缩小防护基线，彻底根除启动黑边锁定**（Issue #363）：
  - 修复 0.3.9 中将防护基准记录放在尺寸变动分支中，导致重建后的 Surface 首次尺寸与旧 Surface 最终尺寸相同时未能激活基准、随后中间过渡缩小（如 854x500）被错误生效并锁定产生黑边的问题；
  - 改为按 SurfaceView 视图实例严格绑定基线，确保任何新视图初次确立尺寸时均能准确激活基准与 3 秒防抖保护窗口。
- **引入粘性沉浸式全屏并在倒车重新获焦后多次重申全屏**（Issue #363）：
  - 为老旧车机全屏兼容标志增加 `SYSTEM_UI_FLAG_IMMERSIVE_STICKY`（标记值确定为 0x180e），解决倒车影像退出后系统原厂底栏被唤出后无法再次自动隐藏的问题；
  - 窗口重新获得焦点后，在 300ms、800ms 与 1500ms 延迟周期内分阶段重申全屏，平抑原厂界面图层退出的滞后干扰。
- **hostapd 前台故障探测由守护进程直接输出独立调试日志**（Issue #330, #348）：
  - 修复部分本田车机 shell 重定向管道始终捕获不到输出、导致 hostapd 启动崩溃原因成谜的问题；
  - 在前台探测执行命令中指定 hostapd 以 `-dd -f` 参数直接将调试日志写入专属日志文件，确保诊断包能完整收录失败现场真实错误。
