老款安卓車機的 CarPlay 方案。

DiPlay Legacy 專為老款 Android 車機（最低支援 Android 4.4 KitKat / API 19）深度最佳化，提供有線與無線 CarPlay 互聯體驗，支援 ARMv7、x86、ARM64 等多種硬體架構。

下載 APK ↓安裝方式

無須越獄、轉接盒、帳號或驗證伺服器。

請安裝在車機上，支援 Android 4.4 (API 19) 及以上。老舊車機優先推薦使用有線 USB 連線（已針對全志 T3、MTK 等底層驅動與 GPU 硬體圖層渲染最佳化）。

重點最佳化老款 Android 車機，支援各類車型有線與無線連線。

熟悉的駕乘體驗

01

安裝到車機

  1. 停車後下載 APK，並透過車機支援的方式安裝。
  2. 開啟 DiPlay，授予所需的藍牙、Wi-Fi／位置與麥克風權限。
  3. 開啟車機內建熱點，若可選請使用 5 GHz。在「設定 → 連線 → 開啟連線設定」中選擇車機內建熱點，準確填寫並儲存名稱與密碼。保持手機 Wi-Fi 與藍牙開啟，與車機配對後點選「連線手機」，並同意手機上的提示。
  4. 有線連線請使用 USB 資料傳輸線，並點選「透過 USB 連線」。若出現 USB、信任或本機 VPN 提示，請確認。

日常使用不需要 ADB。APK 安裝方式取決於車機。無須手動輸入 MAC 位址。

02

v0.2.20 更新亮點

  • 解決日產等車型 USB 權限輪詢異常及崩潰問題，增加防崩保護。
  • 新增並預設開啟『高效硬體圖層渲染 (SurfaceView)』，針對 Android 6 及以下老舊 GPU 徹底解決卡頓。
  • 底層 C 語言驅動支援 USB 自動脫鉤，修復 iPhone USB configuration is busy。
  • 全志 T3 等晶片專屬單 fd 共享與 Android < 9 有線 USB 16KB 傳輸最佳化。
  • 內建官方離線 MFi 憑證資產，支援完全離線連線，無須認證伺服器。
  • 整合 v1 + v2 雙重簽章，解決 Android 4.4/6.0 解析安裝套件失敗。
  • 原生編譯相容 armeabi-v7a (32位 ARM)、x86、arm64-v8a、x86_64 四大架構。

試用前請了解
