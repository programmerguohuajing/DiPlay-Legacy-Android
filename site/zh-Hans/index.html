你的 iPhone。
老款安卓车机的 CarPlay 方案。

DiPlay Legacy 专为老款 Android 车机（最低支持 Android 4.4 KitKat / API 19）深度优化，提供有线与无线 CarPlay 互联体验，支持 ARMv7、x86、ARM64 等多种硬件芯片架构。

下载 APK ↓安装方法

无需越狱、转接盒、账号或认证服务器。

请安装在车机上，支持 Android 4.4 (API 19) 及以上。老旧车机优先推荐使用有线 USB 连接（已针对全志 T3、MTK、日产奇骏等底层 USB 驱动与 GPU 硬件图层渲染深度优化）。

重点优化老款 Android 车机（包括全志 T3、联发科 MT3561、高通、瑞芯微、展讯、Intel x86 车机等），支持比亚迪、日产奇骏等各类车型有线与无线连接。

熟悉的驾乘体验

01

安装到车机

  1. 停车后下载 APK，并通过车机支持的方式安装。
  2. 打开 DiPlay，授予所需的蓝牙、Wi-Fi/位置及麦克风权限。
  3. 开启车机内置热点，如可选请使用 5 GHz。在“设置 → 连接 → 打开连接设置”中选择车机内置热点，准确填写并保存名称和密码。保持手机 Wi-Fi 和蓝牙开启，与车机配对后点击“连接手机”，并同意手机上的提示。
  4. 有线连接请使用 USB 数据线，并点击 Connect with USB。如出现 USB、信任或本地 VPN 提示，请确认。

日常使用不需要 ADB。APK 安装方式取决于车机。无需手动输入 MAC 地址。

v0.2.40 更新亮点

  • 有线 CarPlay 死链检测：iPhone 静默 90 秒后自动重建。
  • VPN 兼容性增强，支持虚标安卓版本的老车机（如全志 T3）。
  • 诊断报告查看器针对低端车机优化，不再卡死。
  • 视频流中断给 5 秒宽限，等 iPhone 重建不再直接杀会话。
  • 第三方应用麦克风无声诊断增强。
  • 无线 iAP2 握手诊断增强。
  • 应用内更新改用国内镜像，国内无需科学上网。
发布说明与校验值 ↗

试用前请了解

本项目基于开源项目 xcertplay / DiPlay 深度重构与兼容，内置离线认证材料。由于签名与上游不同，首次安装请务必先彻底卸载车机上的旧版 DiPlay。老旧车机建议先使用 30 fps 并关闭 HEVC。

更新与签名

包含 v1+v2 签名，满足旧版 Android 安装解析。后续升级可直接在本版本之上覆盖安装。
