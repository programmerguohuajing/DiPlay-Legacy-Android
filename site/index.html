Your iPhone.
CarPlay for legacy Android head units.

DiPlay Legacy brings wired and wireless CarPlay to older Android head units (Android 4.4 KitKat / API 19+), with native multi-architecture support (ARMv7, x86, ARM64).

Download APK ↓How to install

No jailbreak, dongle, account or authentication server required.

Install on the car head unit. Supports Android 4.4 (API 19) and above. Wired USB is recommended on legacy head units (optimized for Allwinner T3, MediaTek, Nissan, and low-end GPUs).

Focused on compatibility with older Android head units (Allwinner T3, MediaTek MT3561, Rockchip, Qualcomm, Intel x86) across various car models.

Install on your car

  1. While parked, download the APK and install it using the method supported by your head unit.
  2. Open DiPlay and allow the requested Bluetooth, Wi-Fi/location and microphone permissions.
  3. Turn on the car’s built-in hotspot (5 GHz if available). In Settings → Connection → Open connection setup, select Built-in car hotspot and save its exact name and password. Keep phone Wi-Fi and Bluetooth on, pair with the car, then tap Connect phone and accept the phone prompts.
  4. For wired use, connect a USB data cable and choose Connect with USB. Approve any USB, Trust or local VPN prompts.

ADB is not required for everyday use. APK installation options depend on the car. No manual MAC address entry.

New in v0.2.22

  • Fix Nissan X-Trail USB permission polling crashes with robust exception guards.
  • Introduce Direct SurfaceView hardware layer rendering (enabled by default on Android <= 6.0) for zero-copy video output and smooth playback on budget GPUs like Mali-T720 / Mali-400.
  • Low-level C USB driver detach mechanism to resolve iPhone USB configuration is busy (errno 16).
  • Shared single file descriptor for Allwinner T3 chipsets and 16 KiB URB batching for Android < 9.
  • Bundled offline MFi authentication assets for standalone operation without remote servers.
  • Dual v1 (JAR) + v2 (APK Signature Scheme) signing to fix package parsing errors on Android 4.4 / 6.0.
  • Multi-architecture native binaries for armeabi-v7a (32-bit ARM), x86 (32-bit Intel), arm64-v8a, and x86_64.
