CarPlay for legacy Android head units.

DiPlay Legacy brings wired and wireless CarPlay to older Android head units (Android 4.2 / API 17+), with native multi-architecture support (ARMv7, x86, ARM64).

Install on the car head unit. Supports Android 4.2 (API 17) and above. Wired USB is recommended on legacy head units (optimized for Allwinner T3, MediaTek, Nissan, and low-end GPUs).

Focused on compatibility with older Android head units (Allwinner T3, MediaTek MT3561, Rockchip, Qualcomm, Intel x86) across various car models.

Install on your car

  1. While parked, download the APK and install it using the method supported by your head unit.
  2. Open DiPlay and allow the requested Bluetooth, Wi-Fi/location and microphone permissions.
  3. Turn on the car’s built-in hotspot (5 GHz if available). In Settings → Connection → Open connection setup, select Built-in car hotspot and save its exact name and password. Keep phone Wi-Fi and Bluetooth on, pair with the car, then tap Connect phone and accept the phone prompts.
  4. For wired use, connect a USB data cable and choose Connect with USB. Approve any USB, Trust or local VPN prompts.

ADB is not required for everyday use. APK installation options depend on the car. No manual MAC address entry.

Release notes & checksums ↗

Before you try it

Refactored and maintained for legacy head units. Install over an existing version only when the package and signing certificate match. Upstream or Debug-signed versions may require reinstalling; save your settings and reports first.

Updates & signing

Signed with v1+v2 schemes for legacy Android compatibility. Future updates can be installed over this version.

Issue Reports & Diagnostics

If you encounter issues, save a diagnostic report in Settings → Diagnostics and file an issue on GitHub: https://github.com/programmerguohuajing/DiPlay-Legacy-Android/issues
